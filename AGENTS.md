# Règles du projet

## Technologies
- Utiliser du HTML, du CSS et du JavaScript simples, sans bibliothèque complexe.
- Privilégier les fonctionnalités natives du navigateur et éviter les dépendances inutiles.

## Nommage
- Nommer les variables en français, avec des noms explicites.
- Conserver les noms imposés par les API natives du navigateur.

## Organisation
- Respecter un découpage de l'interface en trois zones distinctes.
- Si le rôle des trois zones n'est pas encore défini, le faire préciser avant de construire l'interface.

## Auto-tests
- Ajouter ou adapter des auto-tests pour chaque fonctionnalité créée ou modifiée.
- Garder les tests simples et sans bibliothèque complexe.
- Exécuter les tests pertinents avant de déclarer une modification validée.
- Indiquer les tests exécutés, leurs résultats et ceux qui n'ont pas pu être lancés.
- Ne jamais supprimer, désactiver ou remplacer un test par un résultat écrit en dur. Si un test doit changer, le signaler et expliquer pourquoi.
